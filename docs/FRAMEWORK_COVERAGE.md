# Framework coverage

Which frameworks the 30 internal controls are crosswalked to, how many requirements are mapped, and the readiness
each one reaches on the synthetic data. Generated by `python -m secprog coverage`.

**How readiness works:** each requirement maps to one or more controls; the weakest control decides
(pass 1, partial 0.5, fail 0). Readiness is the mean over mapped requirements. Gaps are listed, not scored.
"Ready" counts requirements whose controls all pass.

**Mapping type:** every framework here is **approximate**: the requirement ids are real, the names are
paraphrases and the mapping is our own reading. It is not legal advice or an audit opinion.

## The one gap

AIUC-1 requirement **F** has no internal control yet, so it is shown as a gap. If it were counted as 0, AIUC-1
readiness would drop from 40.0% to 33.3%.
