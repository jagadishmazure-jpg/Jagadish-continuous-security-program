# Source coverage

Public vendor and analyst material that inspired features in this repo, what was built from each, and how
vendor figures are handled. Research was done on 2026-10-31 (America/New_York). No forms were submitted and no
gated content was downloaded.

**No affiliation.** This repo is not affiliated with, endorsed by or built on any vendor named here. No vendor
code, text, scoring formula or UI is copied. Every company *inside* the repo is fictional.

**Vendor figures are claims, never facts.** Every vendor or survey number in section 7 is listed only so a reader
can see what was *not* reused. None of them appears in the code, the reports, the dashboard or any metric. All
numbers this repo reports come from running its own code on synthetic data.

## 2. What was deliberately not taken

- Product names, UI layouts and scoring formulas.
- Any "leader", "#1" or "only" statement.
- Gated reports, webinars, checklists and calculators (not downloaded).

## 3. Research method

Pages were read as data, through a text reader or curl. Notes are kept outside this repo. Where a page was gated
or missing (404), that was recorded and nothing was guessed.

## 4. Labels used in this repo

| Label | Meaning |
|---|---|
| measured | Counted by the code on the synthetic data |
| synthetic | Seeded fake input (devices, vendors, CVE labels) |
| SIMULATED | Output of a stated assumption in code (visits, deal values, costs, RTO, rescans) |
| vendor claim | A figure from a vendor or survey page; listed in section 7 only |

## 5. Framework sources

Requirement ids follow the public framework documents (AICPA TSC 2017, ISO/IEC 27001:2022 Annex A, NIST CSF 2.0,
PCI DSS v4.0, CCPA/CPRA, NIS 2, HITRUST CSF categories, ISO/IEC 42001:2023, AIUC-1, EU CRA, EU AI Act, NIST AI RMF
1.0). Names are short paraphrases, not copied text. See [FRAMEWORK_COVERAGE.md](FRAMEWORK_COVERAGE.md).

## 6. How to check that no vendor figure leaked

`grep` the code and the generated `out/` files for any figure in section 7; none appears. Every number in the
docs is regenerated by `scripts/render_docs.py --check` in CI.
