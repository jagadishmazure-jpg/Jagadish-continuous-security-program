# ADR 0004: Every number labelled and re-checked

**Status:** accepted · **Date:** 2026-10-31

**Context.** Security metrics in demos are often invented or copied from vendor marketing.

**Decision.** Every number is measured, synthetic or SIMULATED, and printed by the code. Documented outputs are
regenerated by `scripts/render_docs.py --check` in CI.

**Consequences.** Numbers can look unflattering; that is intended.
