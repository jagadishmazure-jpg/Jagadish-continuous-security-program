# Glossary

| Term | Meaning here |
|---|---|
| Agent | A small module with one job, an accountable person and decision rights. It proposes; it never approves. |
| Approval gate | The one place a person approves, edits or rejects a proposal; logged with who, when and why. |
| ASM / DAST | Attack surface management / dynamic application security testing (simulated here). |
| Choke point | An edge that sits on many attack paths; cutting it closes all of them. |
| CTEM | Continuous threat exposure management: scope, discover, prioritize, validate, mobilize. |
| EPSS | Exploit Prediction Scoring System: probability a CVE is exploited soon (synthetic values here). |
| KEV | Known Exploited Vulnerabilities catalog (synthetic flags here). |
| Readiness | Mean requirement score for a framework; the weakest mapped control decides. |
| Rubber-stamp | An approval given too fast (under 15 seconds) to have been a real review. |
| SIMULATED | A number produced from a stated assumption, not measured. |
| Tier 0 | Identity systems that control everything else (domain controllers, identity sync, PIM). |
| TPRM | Third-party (vendor) risk management. |
| Toxic combination | Two or more weaknesses on the same asset that are much worse together. |
| Trust Center | A page where customers get security documents and answers, some behind rules such as an NDA. |
| vCISO | A virtual (fractional) CISO; here, a work queue, a roadmap and a mock audit. |
